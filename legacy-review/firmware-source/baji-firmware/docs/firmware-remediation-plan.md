## 0. 目标与边界

**目标**：让当前 ESP32-S3 固件的真实运行链路达到两份 HTML 的交互与显示要求，解决“模块有实现、生产没有接线”，形成可回归、可编译、可上板验收的交付。

参考优先级：
1. [触控引导与滑动动效补充](<C:/Users/admin/Downloads/吧唧触控引导与滑动动效.html>)：与基线冲突时优先。
2. [渲染参考](<C:/Users/admin/Downloads/吧唧渲染参考.html>)：已有业务、页面、视觉、模式、硬件和同步要求。
3. [本次审计](<firmware-html-audit-2026-10-12.md>)：差距追踪索引，不替代参考原文。

明确边界：
- 可以修改当前工程、补测试、生成资源并编译，不自动烧写、不操作 Git、不启动替代 GUI 服务。
- 保留现有正确的 cat3d、触摸、照料、队列与社交算法；先接通与优化，再评估引擎替代。不会未经说明切换整套渲染路线。
- App/云端代码当前不在本方案已确认的工程范围；先产出固件端契约/adapter/测试桩，**只有真实联调才标完成**。
- 没有实机证据时，不宣称帧率、音频、续航、二维码扫码、双机认证已达标。
- 8 字节事件格式保留；新增第15事件、ACK扩展、配对与下行协议先以“提案/待双方确认”交付，不偷偷改变线上契约。
- 不硬编码真实密钥、一次性口令、云端地址；嵌入式持久状态不套用服务端无状态规则，借鉴依赖单向/契约先行/敏感日志禁止原则。

## 2. 实施架构

### 2.1 分工与依赖

保留模块化单体，不引入服务化。

```text
硬件 / BLE / 语音回调
          │ 有界消息投递（不可直接改FSM或LVGL）
          ▼
应用编排（主循环 + 可主机运行的runtime桥接）
   ├─ 会话与认证：连接角色、绑定确认、已认证App
   ├─ 事件管道：FSM sink → offline queue → 已认证App transport
   ├─ 下行管道：解析/校验 → 主循环原子应用 → 模型/时间/画面
   ├─ 教学与新手：任务状态/成功计数/限额/时钟
   └─ FX分发：声音/外圈/飘字；持久化去抖
          │
          ▼
纯业务状态（照料、FSM、教学、motion）
          │ 只读可渲染状态 / 小型effects
          ▼
LVGL UI + cat3d（单一线程拥有）
```

原则：
- 纯FSM/教学/motion不直接访问NVS、BLE、codec或LVGL对象。
- 硬件与radio回调不操作UI、不直接结算宠物，避免FreeRTOS/NimBLE与LVGL线程竞态。
- event sink只入有界内存队列；flash写入与发送有时间预算，不在指尖事件回调里阻塞。
- UI只读模型与状态快照；private preview不发业务事件、不改变真实游戏或教学状态。
- 明确唯一effect消费者，避免调用action返回值与take_fx重复消费、同一照料重复上行。
- 主循环的“时钟→输入/下行→FSM→效果→画面→保存”顺序由组合测试锁定。

工作：
- 保存现状、确定引用HTML的精确规则，不从被截断的大段工具输出推断要求。
- 复跑现有主机套件；核查批处理异常stderr的真实编码/换行根因，修复后验证失败码透传。
- 统一motion参数为可生成/可测试规范；教学参数也进入同一来源。保留业务spec表，避免两个规范互相覆盖。

- 按阶段记录before/after、编译产物与证据；不改动用户参考HTML。

门禁：现有模块回归可复现；新增用例先揭示当前问题；生成器`--check`不会漏新增参数。

### S1：runtime事件、时钟、FX与保存接线（F01/F02/F05）

工作：
- 启动注册FSM sink，生产与测试用同一桥接函数。
- 全局monotonic时钟推进events，输入发生前校准clock，避免前一tick时间给新事件打戳。
- 对照事件定义确认每个动作只报一次，遇见事件唯一生产者，不让FSM与旧social回调重复报。
- 事件tick/save与flush预算化；flash去抖保持，不能在每10ms循环全队列同步发送。
- **修复前先处理安全边界**：任意BLE连接不等于App，peer social连接禁止flush宠物动作；未知/未认证连接只允许握手/受限能力。
- bubble/toast按真实generation/t0更新文本，重复同文案也能重新显示；生命周期从事件发出算起，不在refresh重新计时。
- +9仅成功摸猫触发，不能拒绝也飘；haptic无马达接外圈，声效只消费一次。
- 文案最多两行与省略号；关闭/过期正确擦除旧区域。新记录靠状态版本判断，不用text ID是否变化代替事件身份。

门禁：真实输入桥接→FSM→事件队列→保存/读回；FX重复刷新不续命；同文案连续动作可显示；peer连接不收到动作；断电窗口内的可丢失范围明确写入报告。

### S2：数据、绑定、同步契约与存档（F03/F12/F13/F17/F19）

工作：
- 区分`transport_connected / peer_session / app_authenticated / bound`四种状态。UI手机标志、配对完成、事件上行使用各自正确条件。
- BLE RX单入口按已确认版本/消息类型分流到social或App，不能双方互相覆盖callback。
- App消息只做长度/枚举/UTF-8/边界/版本校验，投递主循环后原子应用；不在NimBLE回调改游戏。
- 下行模型：宠物快照、当前Unix时间与时区偏移、设置、行程/心动、语音回复、绑定/教学重看、扫码确认结果。
- 时间未同步显示/记录为未同步，不伪称18:40是现在；未有时间时新手期限不根据演示时钟强行过期，采用可信绑定时间与明确降级。
- 名字定义12个Unicode码点，UTF-8容量49字节，禁止截断多字节；实际屏幕用可覆盖名字的字体与省略显示，peer协议旧长度不得静默扩容。
- 新存档版本独立迁移测试；读旧v1保留五状态/金币/成长/设置/花色/名字；新增绑定/教学标记默认“未知/待绑定”，**不能自动认证旧任意连接**。
- 不存pair code明文到日志；安全绑定需确认BLE安全/口令挑战与身份认证机制，密钥由设备生成或制造灌注并保存在设备受保护存储。
- discover关闭只关闭社交发现/提示，不误关已认证手机同步或必要配对可见性。

门禁：错误长度/枚举/越界/错误身份拒绝；坏包不部分应用；旧存档读回不丢用户数据；普通连接不自动pair；time同步与夜间亮度一致；扩容名字仍满足现有广告/peer帧界限。

外部条件：App消息编号/会话认证/ACK尚未确认时，交付提案+纯decoder+测试，不擅自宣布线上兼容；固件可验证失败降级，但完整pair状态待真实协议。

### S3：手势与可见反馈（F06/F09/F11/反向取消）

严格参数：

| 参数 | 验收值 |
|---|---|
| tap | <12px且≤300ms |
| axis lock | ≥12px锁轴，此后不换轴 |
| fast swipe | ≥50px且≤500ms |
| slow drag | ≥140px，不限时间 |
| 反向取消 | 最近80ms反向速度>0.3px/ms，优先于快滑/慢拖 |
| commit | `max(120ms,220ms×剩余距离/466)`，三次缓出 |
| cancel | 180ms |
| rubber | `min(abs(delta)×0.25,28px)`，回弹200ms |
| long press | 150ms起环，r224/w6，600ms满，移动≥12立即取消 |
| face dots | 横拖3点固定顶层，松手1.2s后淡出 |
| pressed button | cardHi + 94%，取消/松手恢复 |

工作：
- 用小型有界采样记录末段位置和时间，处理不足80ms、相同时间点、32位时钟回绕，不用总平均速度代替末速。
- 判定纯模块/函数独立测试，UI只消费结果，不再写一份提交规则。
- 长按触发条件同时要求无axis lock；11/12px边界覆盖。
- 按钮只缩视觉，不缩点击热区；blocked按压不会执行操作，也有理由反馈。
- 表盘圆点与长按/方向环独立top overlay，不随snapshot平移。
- 继续保留正确的竖向固定底帧210px淡黑、横向双推、private preview、暂停cat。

门禁：边界139/140、49/50、500/501、11/12、300/301、反拉与回绕；动画时长上界≤220；无目标不提交；轴不变但同轴跨起点更新目标。

### S4：UI脏区、快照生命周期、真实帧率（R01–R04）

工作：
- 将静态画面变化、overlay活动、cat活动、transition各自分节拍；无变化无invalidate，无活动不memset整层。
- overlay计算旧/新bbox并擦除并集，部分canvas invalidate用实际区域；CPU局部重画与LCD送屏脏矩形分别测。
- AOD无3D，每分钟更新时间；off不进行无谓视觉工作，radio/必要唤醒保持。
- `set_target_fps`只在目标变化时重设；elapsed保留余数，不将30fps在10ms tick下固定量化成25fps。dirty不允许无条件突破预算，必要刷新和动画刷新分开。
- 指标区分`target_fps / cat_draw_fps / ui_present_fps / flush_completed_fps`。若BSP无公开flush回调，不冒险覆盖已有驱动callback，记录实际可测项和录屏方法。
- 快照按版本缓存/预热，并明确失效（数据、时间、花色、字体、屏幕）；不要每12px锁轴都同步两次整屏重建。
- 竖向优先live底帧+单目标图，横向两图；完成释放临时图。若有意缓存，设总预算/释放条件并明确不是“用完释放”。
- 分配失败回退保留正确逻辑/取消/阻尼，不崩溃、不让半创建UI泄漏；切屏后恢复live对象的层级/透明度/可点击。
- 半分辨率恢复先评估单实例resize/自有nearest-neighbor blit与DMA余量，不重复引入已知LVGL放大内存故障。
- 不自动换透视条带引擎；现有正交/深度排序方案作为待批准替代。若要严格对齐R算法，将单独列引擎迁移里程碑、视觉golden与内存预算，不与接线修复混合。

门禁：host调度/脏区/分配失败测试；真LVGL路径至少以可编译薄adapter+可测试planner验证，不再仅自证表格；整机30fps仍须真机（目标33.3ms帧间隔，报告P95/P99，不用平均值掩盖长停顿）。低于目标允许HTML规定的20fps降级，但必须标“降级”而非达标30。

### S5：首次配对与真正五步教学（F03/F04）

状态设计：
- 开机2s→未绑定PAIR；已绑定且教学未完成/跳过按明确状态进入教学；完成/跳过后不每次重走。
- 无真实绑定回调时不能拿BLE连接自动完成；测试可注入“经过验证的绑定结果”，必须标测试环境。
- 教学独立任务phase，不等价于普通GUIDE_NEXT动作。

| 任务 | 成功条件 | 返回/错误 |
|---|---|---|
| 1 摸猫 | 点在猫热区且成功反馈 | 点别处看向指尖，不翻页 |
| 2 上滑 | 进入照料且下滑回教学 | 错方向阻尼/文案，不够远弹回 |
| 3 下滑 | 进入状态且上滑回教学 | 同上 |
| 4 左右滑 | 换表盘后反方向换回原表盘 | 单次换屏不直接过关 |
| 5 长按 | 600ms进入voice，松手结束 | 太短提示；结业页点击主屏 |

- 五段r222/w8进度；每2.4s手指循环；8s未成功换帮助文案。
- 二级45%黑遮罩+返回提示，拖动时淡出。
- 底部skip热区直径72；跳过仍进入新手期；App replay不清零已学技能，不重复结算奖励。
- 教学演示private preview，不发照料/表盘/统计业务事件；真正用户动作的计数/奖励则有明确唯一生产者。
- 常规语音8s/VAD规则不因教学而被永久改变。

门禁：从create→boot→真实绑定结果→教学全流程，不用go直接进页；每步错误/往返/跳过/重放/重启；进度与实际任务一致；独立验证“旧点击五次”不能结业。

### S6：新手提示与持久化（F10）

工作：
- 五技能各成功次数饱和至3；配对后三天内且存在未学技能才提示。
- 成功计数以真正完成动作计算，演示不计、拒绝不计、同动作不重复计。
- 180ms静按方向r230/w5/22°+标签，拖动只留当前方向，长按/松手消失。
- 主屏6s空闲演示1.45s，顺序up/down/lr/hold；同次idle一次，每日≤6；任意触摸立即中止。
- care/status/settings前三次进入，400ms后闪两下，每下800ms；第4次停止，用户输入立即停。
- 暗屏、低电、语音、照料操作、转场中不演示；桌面模式是否显示遵循新手闸，不造成持续高功耗。
- NVS存次数/绑定起始时间/日期/当日限额/返回计数，写去抖；时区与跨日行为可测。断电不能让每日额度无限重置。

门禁：72h边界、第三次学会即停、跨日重置额度、6次上限、用户中断、重启恢复、时间未同步/回拨降级。

### S7：硬件、生活同步、遇见、语音与视觉补全

## 4. 测试设计：避免再次“单测全绿但整机断链”

| 层级 | 覆盖 | 不能替代 |
|---|---|---|
| 纯规则 | motion边界、教学phase、新手额度、照料、存档decode | runtime真实接线 |
| 组合runtime | 与生产同一入口/桥接：输入→FSM→FX/events；clock→save；下行→模型→breed | NimBLE/触摸硬件 |
| LVGL/绘制 | top overlay文案/坐标/生命周期、真实invalidate区域、快照分配失败 | LCD实际吞吐/温升 |
| 固件编译 | 真实依赖、IDF/xtensa诊断、链接与内存 | 首次上电、音频本体 |
| 实机 | 触摸5靶、帧完成/录屏、功耗、外设、断电恢复 | App/云端权威结算 |
| 双机+App | 认证、扫码20s、同步、补传、连续两次遇见 | 无条件完整云端安全审计 |

新增测试不通过直接`go()`来证明生产可达；不自行注册一个生产没注册的sink；不只比较自己生成的表；golden分“自身引擎一致”和“HTML视觉一致”两类。

最小关键case：
1. 离线摸猫→队列+1→4/5秒保存边界→重启读回；拒绝不新增成功事件。
2. 普通BLE/peer连接→不得flush；认证App→有预算补传；send失败保留队头。
3. 同文案2次FX、150ms/600ms长按、12px移动取消、每次刷新不续期。
4. 180px拖→末80ms反拉仍160px→取消；slow139不提交、140提交。
5. 新机boot→PAIR；普通连接保持PAIR；验证绑定→五任务；点击五下不通关。
6. 引导跳过→主屏仍新手；第三次技能成功停止该技能；6次日额度持久。
7. idle无overlay时0次合成层invalidate；结束清旧区域；cat降fps不被相同目标重置。
8. NVS v1迁移、未知version/截断blob、安全拒绝；名字12Unicode不截断；坏下行不部分应用。
9. lowbat阻止3D/wake并插电恢复；晚23:00与07:00音量/亮度；QR退出恢复原亮度。
