# 真机接入与验收记录

本清单尚未执行。主机回归、网页渲染和编译均不能代替实际设备记录。当前没有获准写入的端口，也没有真机通过结论。

## 设备与写入前准备

1. 用户确认 Android 手机型号、系统版本和 USB 数据线。开发者选项、USB 调试及授权弹窗由用户自行操作；先只读列举设备，不自动启用或点击权限。
2. 吧唧逐块贴身份标签 A/B，记录型号、SKU、PCB 丝印、电池/扬声器装配和现状，不能用 PRD 历史报告代填。
3. 只读比对接入前后串口，记录准确 `/dev/cu.*`；明确设备身份前不发送探测命令、不刷写。
4. 首次写入前报告现有固件/存档价值和官方恢复包来源。需要备份时先取得读闪存授权，按实际容量只读备份并校验 SHA-256；备份可能含配对密钥，留在本地忽略目录，不上传。
5. 列出将覆盖的地址/分区、对旧 NVS 的影响与回滚方案，取得明确写入授权。禁止 `erase-flash`；旧固件分区未知时，不能声称可安全保留旧存档。
6. 记录准确 APK、app.bin、bootloader、partition-table、依赖锁与 SHA-256；只使用已校验产物。

## App 单机验收

- [ ] 首次安装显示真实本地猫/状态/原始房间；断网可运行，不请求定位、相机或麦克风。
- [ ] 八种照料分别完成、取消和切后台；未完成不扣币或奖励；连续点击/冷却有反馈。
- [ ] 原始接鱼 20 秒，可移动接鱼，实际分数与结算一致；取消或离开应用不重复奖励。
- [ ] 愿望、成长、手记、改名保存成功；强退再开保持 petId/revision。
- [ ] 系统文件选择器导出并恢复备份；同猫恢复 revision 前进且不重复奖励；坏备份/存档不静默新建宠物。
- [ ] 中文输入、字体放大、竖屏触控、前后台与 WebView 正常，无白屏或越界。

## 单板 BLE 验收

- [ ] 用户主动点击权限/搜索，自己确认附近设备授权和系统配对；不自动开启蓝牙。
- [ ] 准确选择目标设备；屏幕六位码可读，输入后加密认证成功。错误码、取消、拒绝权限均可恢复。
- [ ] 真实订阅 TX、写入 RX、接收完整快照；petId/revision/数值一致；MTU 分片和通知实际发生。
- [ ] 实际触摸小猫，吧唧先持久排队，App 只结算一次，ACK 后设备出队并显示确认状态。
- [ ] 断开、离开应用、关闭蓝牙后重连；设备恢复广播，离线队列按原 ID 重放，无重复奖励。
- [ ] App 落盘后 ACK 前退出，重连得到 duplicate，不重复奖励；保留两端实际状态或日志。
- [ ] 吧唧断电/重启保留快照、counter、事件和配对；手机重启/强退可恢复。
- [ ] 不同 petId、旧 revision、同 revision 不同内容均不覆盖；存储失败不发成功 ACK。
- [ ] 手机忘记设备后可经吧唧配对管理重新配对，不清猫/队列；隔离事件按原 ID 重试。
- [ ] 圆屏裁切、触控方向、降亮度/唤醒正常；记录内存、长时间稳定性、温度和电量变化。
