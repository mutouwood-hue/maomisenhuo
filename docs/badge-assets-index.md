## 固件边界与官方规格交叉核对

- 官方当前资料：Waveshare ESP32-S3-Touch-AMOLED-1.75C，ESP32-S3R8、32 MB NOR Flash、8 MB PSRAM、466×466 AMOLED/CO5300 QSPI、CST9217 I²C 触控。分 SKU、电源和 BSP 对照见[硬件交叉核对](hardware-cross-check.md)。
- Waveshare 官方示例仓提供 1.75C managed BSP（`waveshare/esp32_s3_touch_amoled_1_75c` `^3.0.0`），ESP-IDF 5.5+ 路线和 LVGL v9 demo；其当前 CI 说明列 5.5.5/6.0.2。项目仍需根据确定的 tag/commit 固定精确依赖。
- 本地开发 ZIP 有标注 LVGL v9.5 的 C 页面文件；这只说明页面代码按该版本生成，不单独证明其和官方 BSP/本项目 firmware 构建完全兼容。
- 官方产品介绍称内置扬声器，资源图标注扬声器焊盘，并列出 ES8311、ES7210 和双麦克风；具体设备的 SKU/扬声器装配及输出由实物核对。本阶段不采集麦克风音频。
- 用户现有两块设备，目前一块可用。硬件版本/PCB revision 未从网页推断；PRD历史文档的 v0.2 不绑定两块现有板。真机连接/双机互遇仍未本轮复验。
- 渲染参考与目标运行时要分开：电脑 HTML/工具包可能用于设计验证，不自动等同于可运行固件或端侧3D实现。
- 外设：官方列 QMI8658 IMU、AXP2101、音频 codec/麦克风通路和扬声器。首期不依赖 NFC/震动，语音/麦克风保持关闭。实物装配和软件驱动仍须核对。
- 存储与BLE：PRD转述历史报告称曾修复主任务栈溢出和 BLE 断线后广播不恢复；该证据来自文档转述，需拿到仓库、commit、测试记录后审查，不在本轮复写/背书。
- 未验证项：当前板 SKU/revision、屏幕与触控运行方向、实际帧率/内存/功耗、BLE 稳定性、扬声器是否实装及输出、第二块设备双机行为。详见硬件交叉核对。

## 最新 PRD 端间职责提示

PRD 7.6 同步概要：App→吧唧同步外观编号、时间和生活状态；吧唧→App回传摸摸/唤醒等互动事件，由 App 依规则结算；遇见记录由吧唧缓存、App转云；协议字段和 BLE 服务/特征待 M1 技术验证。此表是需求概要，不是正式协议。PRD也写到按住说话由吧唧收音、手机识别且不存音频；本项目当前约束是语音仅默认关闭的模拟规划，需以后单独审查。新版 PRD 修订还将相遇世界扩展为自动长成后可由主人整理摆法。
