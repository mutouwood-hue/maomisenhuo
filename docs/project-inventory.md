1. 打开 App/模拟器看到一只猫和初始状态；

## 工程分层建议

- `assets/` 是有来源、有版本、只读基线；任何转换产物注明工具与版本。
- `app/`、`firmware/` 分别拥有平台 UI/持久化和板级驱动/渲染，不互相复制业务实现。
- `protocol/` 拥有跨端数据模型、消息版本、兼容与错误语义；先离线 JSON/fixtures，再 BLE 传输，云端适配另行演进。
- 云服务保持后续独立边界，不与第一个本地闭环捆绑。
- 手机目标已定 Android 优先；建议 Kotlin/Jetpack Compose + Room + Android BLE GATT；首阶段 App 临时离线结算方案仍由主会话审批跨端契约。小点狗作为产品总领，Codex 负责执行和独立审查。
