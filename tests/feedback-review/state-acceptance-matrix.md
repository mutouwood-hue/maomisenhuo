# 事件反馈状态验收矩阵

日期：2026-10-15。对应 [event-coverage.md](event-coverage.md)。本文件是待执行验收用例，不宣称模拟器、WebView或真机已通过。既有host规则回归不等于本反馈链通过。

## 状态契约

`真实触发 → 预检通过 → 初始反应/进行中 → 真实输入完成 → 保存中 → 原生持久成功 → 结果反馈 → 持续状态`。

规则拒绝、取消、存储失败分别为独立出口；不能进入成功出口。正在擦拭可以有对应动作，存储未成功前不能永久去掉wet或显示健康到账。JS以已提交原生状态为权威，表现失败不得反过来把已提交事务当业务失败再提交。

## 取证标准

每项记录源代码版本/hash、运行环境、真实输入、桥接请求/应答、事务前后存档和可见过程；不要用mock的“success”证明真正保存或BLE。轻量JS可证明去重/取消分支，host可证明规则与存储故障，模拟器可证明Android/WebView交互；真实触屏、蓝牙、设备掉电仍须硬件验收。被并行修改的实现重新读取后才能标“通过”。

用户要求的最终验收单位是每个实际事件与选项的完整链条；一段雨天demo通过不能替代C01..S07的覆盖。
