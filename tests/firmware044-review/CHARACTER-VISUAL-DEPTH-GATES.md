# 044 A 主角可读性与脚底遮挡补充门

## 范围

按Root转述的当前A r4人工观察：猫偏暗棕、眼睛暗、脚掌似被地毯裁掉或出现碎边。**这是待定位的视觉反馈，本reviewer尚未读取044在途源或最终像素，不预判是地毯深度、ROI裁切还是低分辨率采样。** 本文追加必要验收门，不修改原设计及其hash，不放行044候选。旧043/reference保持原样。

允许有界的新A ambient或明确LUT提亮；原PCAT文件/纹理身份及原骨骼规则继续保留。新A像素必须建立自己的golden，不继承旧043 RGB exact。本文不要求新增阴影、写实材质或额外任务。

## 先定位，再调整

1. **真实变换后的脚底。** 从实际PCAT层级、当前pose、缩放和world transform得到每只脚的最终mesh顶点及minY，不能从未变换模型bbox或一张截图推断。列明实际支撑面的floor/rug top高度、毯子x/z覆盖范围与脚底差值；越界点用其实际所在支撑面，不能对全场统一加毯高。抬脚/跳动等原动画阶段不强求四脚同时接地，区分应承重脚与离地脚。
2. **实际射线/深度/owner解释可疑像素。** 对被截脚掌附近选取若干最终physical像素，回查其全局nearest logical坐标、脚/毯/地候选三角、camera depth量化值和最终owner。应由实际生产深度规则决定胜者；用独立解析平面或少量射线交点复核可疑点，不能只用同一raster的full/cached自比来证明模型没穿地。
3. **分开排除ROI与采样。** 同姿态比较完整frame与完整bbox ROI，以及无地毯的诊断对照；诊断对照只作定位，不作为产品隐藏地毯。全部padded bbox仍须包含在ROI，physical展开不能丢末行列。低分辨率nearest造成的台阶可单列，不可将真实owner错误、缺失脚掌或裁切统称为像素风。
4. **不使用无依据的z-bias。** 不给猫整体任意深度优先权，不关闭毯/盆/柱的深度，也不以强行覆盖房间像素遮掩问题。若真实几何支撑关系需修，明确新A布局/支撑面或模型落点差异，并重新生成对应cache及golden；若只改光照，不得混入几何修复的宣称。

## 必要姿态和遮挡矩阵

|范围|正控|必须保留的反例/判定|
|---|---|---|
|站立/idle与转头|正面、斜面、当前默认方向的完整脚掌与眼部|脚底不穿实际支撑面；头转动时眼睛不是一团暗块；不要求背向时看见双眼|
|walk/paw/其它原动作|至少起点、中点、极值、结束；覆盖原动作里实际离地/接地阶段|原骨骼运动不改；抬起的脚允许离地，承重脚不陷入毯/地；结束不残留旧碎边|
|floor↔rug边缘|脚位于毯内、毯外和跨边，含四边及角部|面高度和覆盖区域一致，不能仅中心姿态无误就称所有接触通过|
|盆/柱遮挡|猫在物体前、后、交界的真实构图|物体仍能正确遮住位于后方的猫；猫在前方仍可见。强制猫最前/关闭深度的负控须被oracle识别|
|尺寸阶梯|被选中的1–2个variant分别看原生physical466图及眼/脚无滤镜放大crop|不能用233版本可读性替代96/128；nearest放大crop须标倍率，插值美化图不能当验收证据|
|dirty/full与cache/full|上述关键姿态都用同一时刻、同一新A配置比较|各variant RGB/Z/owner cache/full exact；所有中间partial composition对full一致，old/new物理ROI残影负控仍有效|

## 提亮门与资源边界

- 记录明确ambient/LUT参数及其作用阶段，保留前后同pose/相机/尺寸图；原PCAT资产hash、texture采样身份、骨骼变换规则精确核对。允许对新A输出有意改变颜色，不能继续标为旧原JS RGB exact。
- 独立看原生尺寸猫的橘色主体、眼睛与面部、四肢轮廓；列出眼部/主体/背景代表像素及可见区域，防止整体提亮把眼睛、纹理或轮廓洗平。无统一凭空对比度数值代替实际看图。
- 光照/LUT在full与cached路径必须一致；若影响静态房间或cache身份，将其纳入生成key/fingerprint和失配拒绝。若只影响猫shade，也要在其渲染参数及新golden中固定。
- 原先单USB writer、immutable physical front、GUI锁/drain、真实动作3s TTL、first-byte parser、无新reward/事务及资源总账门继续有效。颜色修复不能引入新task、额外front、全屏RAM、未计入的每像素buffer或降低capture guard。
